## Kariyer Atelier

Kariyer Atelier helps job seekers prepare and tailor CVs, compare them with job listings, and track applications. Version 17 was deployed to a restricted test site.

| Development stage | What was implemented |
| --- | --- |
| v1–v4 · CV workspace | CV editor, PDF export, keyword and skill matching, application tracking, account-based storage, cover letter and interview preparation tools, data export, PDF/DOCX/TXT import with preview, and automatic section detection. |
| v5–v6 · Role-specific CVs | Independent CV versions per vacancy, CV-to-job comparison, application checklists, and copies that preserve the base CV. |
| v7–v10 · AI integration and usability | Server-side OpenAI integration with usage limits, templates, eight-point quality checks, onboarding, unsaved-change warnings, URL validation, and restoring quota when an AI request fails. |
| v11–v13 · Drafts and review | Application summary drafts, side-by-side AI suggestions for experience entries with selective saving, and bilingual CV and cover letter adaptation. |
| v16–v17 · Administration and monitoring | Admin dashboard with server-side access checks, usage and cost metrics, user export and deletion of usage records, and monitoring for API configuration, quota, and errors. |

TypeScript checks, production build, and deployment passed for v17. Live end-to-end checks for admin workflows and API error handling were still pending. An earlier live AI test was blocked by provider quota. Public registration, payments, subscriptions, and the dedicated interview coach are not presented as released features.
